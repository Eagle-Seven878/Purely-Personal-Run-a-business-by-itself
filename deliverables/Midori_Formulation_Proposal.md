# Starting-point formulations for Midori Naturals Cosmetics, Inc.

**Status:** concept formulas for bench development. Not a validated, safety-assessed or claim-approved formula. Midori's chemist must adjust to their raw-material inventory, run stability, preservative challenge and safety assessment, and confirm regulatory and claim wording for each target market. Midori's capabilities and "natural" standards (if any) were not verified; confirm them first.

## 1. What is known about the two actives' formulations

**Fision® GlowPlex (TRI-K)**
- INCI: Water, Niacinamide, Pisum Sativum (Pea) Seed Extract, Chenopodium Quinoa Seed Extract. Use 1-5%, pH 4-8 (deck). Trade press repeats the same INCI and the supplier's own claims; no independent studies found ([Cosmetics Design](https://www.cosmeticsdesign.com/Article/2021/10/06/TRI-K-introduces-niacinamide-peptides-for-skin-glow), [Personal Care Magazine](https://www.personalcaremagazine.com/story/36696/tri-k-launches-niacinamide-with-peptide)).
- The deck gives four sample formulas (clay mask, prepping moisturizer, tinted moisturizer, hydration cream at 1%) and the clinical test cream (5% in a stearic-acid vanishing cream). In every one, GlowPlex goes in the late/cool-down phase.
- Not found online: a published serum formula. A TRI-K "Dew You Glow Serum" page appeared in search results, but the host could not be reached from this session. Ask TRI-K for it.

**MadeWhite™**
- The deck (BioSpectrum) gives no finished-product formula, only the raw-material composition (water 90-98%, madecassoside 0.4-1.5%, pentylene glycol 2-5%) and 2% as the clinical use level.
- A SpecialChem listing shows MadeWhite under **Clariant**, INCI Aqua, Madecassoside, Pentylene Glycol ([SpecialChem](https://cosmetics.specialchem.com/searchsites/searchproducts/b-whitening/a-decorative-cosmetics-make-up/o-bio-organic/s-clariant)), while the deck is BioSpectrum-branded. Confirm who currently supplies it before ordering.
- No use-level or starting formula was found. Request the technical data sheet.

## 2. Recommendation

Make **two SKUs, one hero active each**, so each claim stays inside the evidence:

| SKU | Active | Why |
|---|---|---|
| **A. Daily Glow Cream** | GlowPlex 5% | Matches the clinical condition (5% in a cream, twice daily, 28 days); glow/radiance story |
| **B. Dark-Mark Serum** | MadeWhite 2% | Matches the 2% clinical level; post-inflammatory dark marks; water-soluble, suits a serum |

Do **not** launch a MadeWhite + GlowPlex combination until you have your own data: neither deck tested them together. It is a reasonable third R&D prototype (e.g., 2% + 3%).

## 3. Formula A: Daily Glow Cream (o/w emulsion), 100 g

Structure follows TRI-K's sample moisturizers and clinical cream, with generic ingredient functions so Midori can substitute from stock.

| Phase | INCI / function | % |
|---|---|---|
| A | Water | q.s. 66.80 |
| A | Glycerin | 4.00 |
| A | Pentylene glycol | 1.00 |
| A | Chelator (e.g. tetrasodium glutamate diacetate) | 0.10 |
| A | Xanthan gum | 0.30 |
| B | Glyceryl stearate citrate (emulsifier) | 2.50 |
| B | Cetearyl alcohol | 3.50 |
| B | Caprylic/capric triglyceride | 5.00 |
| B | Shea butter | 3.00 |
| B | C12-15 alkyl benzoate (or plant-derived ester) | 3.00 |
| B | Squalane | 2.00 |
| B | Tocopheryl acetate | 0.30 |
| C | **Fision® GlowPlex** | **5.00** |
| C | Sodium hyaluronate solution (1%) | 2.00 |
| C | Panthenol | 0.50 |
| C | Preservative system (e.g. phenoxyethanol + ethylhexylglycerin, or Midori's approved system) | 1.00 |
| | **Total** | **100.00** |

**Process:** disperse xanthan in glycerin, add to water, heat A and B separately to 75 °C, emulsify B into A with homogenization, cool to <40 °C, add C, adjust pH to 5.0-6.0 (citric acid or sodium hydroxide). Confirm GlowPlex's temperature limit with TRI-K.

## 4. Formula B: Dark-Mark Serum (gel), 100 g

| Phase | INCI / function | % |
|---|---|---|
| A | Water | q.s. 86.65 |
| A | Glycerin | 3.00 |
| A | Butylene glycol (MadeWhite is soluble in it) | 3.00 |
| A | Chelator | 0.10 |
| A | Sodium hyaluronate (powder) | 0.05 |
| A | Hydroxyethyl acrylate / sodium acryloyldimethyl taurate copolymer (pH-tolerant thickener) | 1.00 |
| B | **MadeWhite™** | **2.00** |
| B | Panthenol | 1.00 |
| B | Allantoin | 0.20 |
| B | Pentylene glycol | 2.00 |
| B | Preservative system | 1.00 |
| | **Total** | **100.00** |

**Process:** pre-disperse the thickener in water/glycerin, hydrate, then add B at room temperature. Adjust pH to 4.5-5.5, within MadeWhite's supplied range (3-6). Water phase only: MadeWhite is insoluble in oils.
**Packaging:** opaque or UV-protective. In the deck, MadeWhite in a lotion lost much of its activity at 45 °C with light, and a toner held up better.

## 5. Prototype and test plan

1. Bench batches: A (GlowPlex 5%), B (MadeWhite 2%), plus optional C (2% + 3% combination).
2. Stability: 4, 8 and 12 weeks at 4, 25 and 45 °C, light and dark; check pH, viscosity, color, odor; assay actives if possible (MadeWhite's weak point is heat + light in emulsions).
3. Preservative challenge test and microbial testing.
4. Safety: irritation/HRIPT through a qualified lab (GlowPlex has none shown in the deck; ask TRI-K).
5. Efficacy: small panel with a placebo, and a niacinamide-only arm for the glow cream, since the deck lacks that comparison clinically.

## 6. Questions to settle with Midori and the suppliers

- Midori's minimum order quantities, in-stock emulsifiers, preservative system and any natural/organic certification rules (these can exclude phenoxyethanol or certain esters).
- Target markets and claim wording ("brightening" vs "whitening"; dark spots as a cosmetic appearance claim).
- GlowPlex: processing temperature limit, compatibility, stability and safety dossier.
- MadeWhite: current supplier, recommended use level, finished-product pH range and light-stability guidance.
